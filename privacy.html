Политика конфиденциальности Kadrimo Agents

Действует с 28 октября 2026 года.

Kadrimo Agents — внутренний инструмент команды YouTube-канала «Кадримо». Им пользуются только участники команды для управления собственным каналом. Приложение не предназначено для посторонних пользователей.

Какие данные используются

После входа через Google приложение с разрешения владельца канала обращается к YouTube Data API и YouTube Analytics API:

  • читает статистику и аналитику нашего канала и его видео;
  • загружает видео и обложки, меняет описание и оформление нашего канала;
  • читает публичные комментарии к нашим видео и публикует ответы от имени канала;
  • читает публичные данные других каналов и видео (названия, счётчики просмотров) для анализа трендов.

Хранение и передача

Токен доступа хранится только на компьютере команды и не передаётся третьим лицам. Данные YouTube используются только для работы канала, не продаются, не передаются рекламным сетям и не используются для обучения моделей ИИ. Отчёты хранятся локально.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use. Приложение использует YouTube API Services; см. также Политику конфиденциальности Google.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. После отзыва сохранённый токен перестаёт работать и удаляется.

English summary. Kadrimo Agents is an internal tool used only by the Kadrimo channel team to manage its own YouTube channel via the YouTube Data and Analytics APIs: reading our channel analytics, uploading videos, updating channel branding, and replying to comments on our videos. Public data of other channels is read for trend analysis. Tokens stay on the team's computer; data is not sold, shared, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at any time at myaccount.google.com/permissions.
